Content Block — 3 Types
📝 Text
Regular prose. Stored as rich text (bold, italic, etc). Most blocks are this type.
⑂ Choice Point
A decision node. Has 2–4 choices. Each choice sets story variables and optionally jumps to a different scene (for big branches).
display: inline | chapter-gate
◈ Conditional Fragment
Base text + override snippets. At render time, the reader's state is checked and the matching override (if any) replaces the base.
Story Variables — the "memory" of choices
Defined per series. Set by choices. Read by conditional fragments. Carry forward through all five books.
spare_victim = true
burned_letter = false
ally_count = 2
Supported types:
boolean — true/false flags (most common)
number — counters (e.g. kill count)
string — named choices (e.g. "north")
Reader Session — tracking progress & enabling rewind
Current Position
Which scene + block the reader is on right now
Story State
Current values of all story variables (the accumulated result of all choices made)
Choice History
Ordered list of every choice made. Rewinding pops back to any point and recalculates state.
