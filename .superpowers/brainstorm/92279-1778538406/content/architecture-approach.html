A — Full Web App (Recommended)

Runs in your browser, data stored in a database. Access it from any device. When you're ready to open source it, others can deploy their own instance — just like self-hosted Wattpad. Closest match to your vision.

Pros

  • Access from any device
  • Natural fit for open source
  • Easiest to share stories

Cons

  • Needs a server to run
  • More setup upfront

B — Desktop App

Like Scrivener — installs on your Mac, data lives on your machine. No internet needed. Great for privacy-focused personal use, but harder to share or use across devices without manual syncing.

Pros

  • Fully offline
  • Completely private
  • No hosting costs

Cons

  • Harder to share or open source
  • Tied to one machine

C — Local Web App

Looks and feels like a website but runs entirely on your Mac — no hosting needed. When you're ready to open source it, it deploys to the cloud with minimal changes. Best of both worlds.

Pros

  • No hosting costs now
  • Clean path to deploy later
  • Familiar browser UX

Cons

  • Need to start a server to use it
  • Still tied to one machine until deployed
